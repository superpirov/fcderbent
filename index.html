# Клуб ИВНПМячиРМО
Регламент турнира соответствует правилам FIFA: победа — 3 очка, ничья — 1, поражение — 0. Места распределяются по: очкам → разнице мячей → количеству забитых мячей. И — игры, В — выигрыши, Н — ничьи, П — проигрыши, РМ — разница мячей, О — очки.
