# ФК «Дербент» — официальный сайт

Современный сайт любительского футбольного клуба «Дербент» (осн. 1966).
Статический сайт без сборки: HTML + CSS + JS. Публикуется на GitHub Pages.

## Разделы сайта

- **Главная** — hero-блок, новости, сыгранные матчи (все клубы лиги + фильтр «ФК Дербент»), турнирная таблица чемпионата Дагестана (пересчитывается автоматически по правилам FIFA: 3–1–0)
- **Клуб** — Визитная карточка, Руководство (с биографиями), Вакансии (с формой), Стадион
- **Команда** — Состав команды (вратари → защитники → полузащитники → нападающие, страницы игроков), Тренерский штаб
- **Спортивная школа**, **Контакты**
- **Админ-панель** — `admin.html`

## Админ-панель (no-code)

Откройте **`admin.html`** на сайте. Пароль по умолчанию: **`derbent1966`**
(сменить можно в разделе «Настройки» → экспортируйте data.js после смены).

Что можно редактировать без кода:

- Общие настройки (название, hero главной страницы, логотип, контакты, пароль)
- Новости (добавление / редактирование / удаление / порядок)
- Клубы лиги (логотип, название, город, цвет, описание)
- Матчи (счёт, дата, стадион, команды) — таблица пересчитается сама
- Игроки по позициям, Тренерский штаб, Руководство (фото, биографии)
- Тексты вакансий и страницы «Стадион» / «Спортивная школа» (блоками)

### Как опубликовать изменения

1. В админке нажмите **«Экспорт data.js»** — скачается файл `data.js`.
2. Замените им файл `data/data.js` в репозитории.
3. Сделайте commit и push — через минуту изменения будут на сайте.

Кнопка **«Сохранить (предпросмотр)»** применяет изменения только в вашем браузере — удобно проверить результат до публикации (на сайте появится плашка «Предпросмотр», её можно сбросить).

```

├── club-stadium.html     Стадион
├── team-squad.html       Состав команды
├── team-staff.html       Тренерский штаб
├── player.html           Страница игрока (?id=)
├── person.html           Страница персоны (?id=)
├── news.html             Страница новости (?id=)
├── school.html           Спортивная школа
├── contacts.html         Контакты
├── admin.html            Админ-панель
├── assets/               CSS и JS
├── data/data.js          ВСЕ данные сайта (редактируется админкой)
├── images/               Логотипы и фото
├── _import/              Исходный WordPress-экспорт (матчи, клубы)
└── scripts/build-data.mjs  Генератор data.js из _import + data/template.json
```

## Локальный запуск

Просто откройте `index.html` в браузере, либо:

```
npx serve .
```

## Публикация на GitHub Pages

1. Push этого репозитория в `superpirov/fcderbent`.
2. GitHub → Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по адресу `https://superpirov.github.io/fcderbent/`.
4. Свой домен подключается в Settings → Pages → Custom domain.
